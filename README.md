# Online Election Voting Management System (OEVMS)

## Overview

A secure full-stack online voting system developed as a capstone project, designed to ensure fair, reliable, and tamper-resistant election processes. The platform enforces strict voting rules and provides controlled workflows to maintain data integrity.

## Features

* Role-based access control for system users
* One-vote-per-user enforcement using backend validation and database constraints
* Real-time vote processing and tracking
* Time-restricted voting windows for controlled election periods
* Audit logs for tracking voting activity and ensuring transparency
* Email notifications for voter verification and system alerts

## Tech Stack

* Laravel (PHP)
* React
* MySQL
* JavaScript
* PHPMailer (Gmail SMTP)
* REST API Integration
